# Treewidth-nine reference data

These files record the completed computation behind [f(9)=42](../../proof-nine.md).
They are reference outputs, not a substitute for reproducing the classifications.
The full driver regenerates its inputs in dependency order in a separate work
folder; the shorter mode deliberately uses the saved final residue lists.

The large intermediate 31-edge graph lists are generated by the full run and
are not committed. The final Python audit report omits its repetitive per-seed
rows here; a reproduction writes the complete report. The witness and its
115,440-state lower-bound certificate are in [../witness42.json](../witness42.json).

Original run reports preserve their source fingerprints and absolute paths as
provenance. Those paths are **not runtime dependencies**. Packaging moved the
scripts into `scripts/nine`, replaced the research-workspace helper imports,
and added an orchestration driver; new runs therefore have new fingerprints.
`package-manifest.json` hashes the packaged files using repository-relative
paths. It is a file-integrity record, not a mathematical certificate.

`treewidth31-prefix-audit.json` records agreement with unpruned enumeration
through order 12. `prefix-audit.json` and `genreg-treewidth-audit.json` are checks
rerun using the packaged code. These small-case audits complement the
independent positive-order checks; they do not replace generator completeness.
